# Mehedi Hasan Nirzan — Portfolio

This folder is ready for GitHub Pages. It uses plain HTML and CSS, so it does not require installation, payment, or a build command.

## Pages included

- About: `index.html`
- Research: `research/index.html`
- Projects: `projects/index.html`
- Experience: `experience/index.html`
- Education: `education/index.html`
- Skills: `skills/index.html`
- Achievements: `achievements/index.html`
- Contact: `contact/index.html`
- Error page: `404.html`

## Important files

- Edit colors, fonts, spacing, and layout in `styles.css`.
- Replace your photograph at `assets/mehedi-hasan-nirzan.webp` without changing the filename.
- Replace your CV at `assets/Mehedi_Hasan_Nirzan_CV.pdf` without changing the filename.
- Do not rename or move the page folders unless you also update the navigation links.

## Quick local preview

Open `index.html` in a browser. Every internal navigation link uses an explicit `index.html` path, so the pages also work before publishing.

## GitHub Pages

Upload the contents of this folder—not the enclosing ZIP file—to the root of a public repository named `YOUR-USERNAME.github.io`. In the repository's Pages settings, publish from the `main` branch and `/ (root)` folder.
